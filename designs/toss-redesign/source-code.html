Responsive Breakpoints

/* Tablet: ≤1023px */ - Sidenav becomes slide-in drawer (translateX(-100%) → 0) - Hamburger button visible - Bottom nav visible - Search bar hidden - Content padding-bottom: 80px (for bottom nav) /* Mobile: ≤640px */ - All grids collapse to single column - Page headers stack vertically - Filter pills scroll horizontally - Card CTA buttons stretch full-width - Avatar sizes reduced - Font sizes scaled down - Input font-size: 16px (prevents iOS zoom) /* Safe area (notched phones) */ - padding-bottom: max(6px, env(safe-area-inset-bottom)) - Applied to bottom nav and content
